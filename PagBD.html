Conceptos básicos de Bases de Datos

1. ¿Qué es una Base de Datos?

Una base de datos es un sistema donde se almacena información organizada para poder buscarla, modificarla y administrarla fácilmente.

2. ¿Para qué sirve una Base de Datos?

Sirve para guardar información de forma ordenada, facilitar su búsqueda y permitir que los datos se puedan actualizar o eliminar cuando sea necesario.

3. ¿Qué es un CRUD?

CRUD es un conjunto de operaciones básicas que se realizan en una base de datos.

Definición de cada letra

Create: Crear nuevos datos.
Read: Leer o consultar información.
Update: Actualizar datos existentes.
Delete: Eliminar información.

4. ¿Qué es un Campo?

Un campo es una columna dentro de una tabla que guarda un tipo específico de dato, por ejemplo nombre, edad o correo.

5. ¿Qué es un Registro?

Un registro es una fila de una tabla que contiene todos los datos de un elemento.

6. ¿Qué es un Dato?

Un dato es una pieza de información que se guarda en la base de datos, como un número, una palabra o una fecha.

7. ¿Qué es un Diagrama Entidad Relación?

Es un esquema visual que muestra las entidades de una base de datos y la relación que existe entre ellas.

También aparece la relación “Es en el taller”, donde cada empleado tiene un cargo, mientras que un mismo cargo puede pertenecer a varios empleados.
